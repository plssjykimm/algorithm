# 정렬 알고리즘 비교 디스플레이

동일한 샘플 데이터를 11가지 정렬 알고리즘에 적용하고 진행 과정과 성능 통계를 한 화면에서 비교하는 웹 프로그램입니다.

지원 알고리즘: 버블, 선택, 삽입, 병합, 퀵, 힙, 셸, 빗질, 칵테일, 계수, 기수 정렬. 조사 자료와 선정 근거는 [ALGORITHMS.md](ALGORITHMS.md)를 참고하세요.

## 실행

프로젝트 폴더에서 다음 명령을 실행한 뒤 브라우저에서 `http://127.0.0.1:8080`에 접속합니다.

```powershell
node server.js
```

외부 패키지 설치는 필요하지 않습니다.

## 테스트

외부 패키지 없이 Node.js 내장 테스트 러너를 사용합니다.

```powershell
node --test
```

## 측정 기준

- 경과 시간: 정렬 시작부터 해당 패널의 애니메이션이 끝날 때까지의 시간. 실행 중 실시간으로 갱신되며 완료 후 유지됩니다.
- 반복 횟수, 비교 횟수, 자리 바꿈 횟수, 값 쓰기 횟수는 알고리즘 실행 중 누적됩니다.

`자리 바꿈`은 두 데이터의 배열상 위치를 서로 바꾸는 연산입니다. `값 쓰기`는 삽입 정렬이나 병합 정렬처럼 배열의 특정 위치에 값을 직접 써 넣는 연산입니다.

`반복`은 비교, 자리 바꿈, 값 쓰기, 기준값 선택을 수행한 전체 처리 단계 수입니다. `비교`는 두 값의 크기나 순서를 확인한 횟수입니다.

상세 설계와 완료 조건은 [PLAN.md](PLAN.md)를 참고하세요.
